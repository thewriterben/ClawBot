# raw/robotics/

Domain sources: papers, specifications, datasheets, standards, textbook extracts.

**Empty.** Deliberately — see the "empty half" section of [`../../CLAUDE.md`](../../CLAUDE.md).

Every robotics page this wiki does not have is missing because the source behind it is missing. The alternative — writing kinematics and actuator pages from an assistant's own recall — would produce fluent, mostly-correct, entirely uncited prose, filed into a wiki whose whole purpose is provenance, and indistinguishable on the page from something that had been researched.

[`../../concepts/open-questions.md`](../../concepts/open-questions.md) is the reading list that fills this directory.

Sources here are **immutable**. If one is wrong, the correction is a wiki page saying so, not an edit.
