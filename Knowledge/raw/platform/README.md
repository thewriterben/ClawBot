# raw/platform/

Sources about this platform and how it works.

- `llm-wiki.md` — the LLM Wiki idea document this directory is an instantiation of. Summarised in [`../../sources/llm-wiki-pattern.md`](../../sources/llm-wiki-pattern.md).

Most platform sources are **not copied here.** They live in sibling repos, are already under version control there, and are cited by repo-relative path (`OpenBuildCore/DECISIONS.md`, `OpenDesignCore/wiki/log.md`). Copying them would create a second copy that drifts — precisely the failure OpenPartsCore exists to end.

A source gets copied into this directory only when it has no other home, as `llm-wiki.md` did.

Sources here are **immutable**. If one is wrong, the correction is a wiki page saying so, not an edit.
